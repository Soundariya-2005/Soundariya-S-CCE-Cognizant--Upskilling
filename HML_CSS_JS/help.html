Frequently Asked Questions

How do I register for an event?

Navigate to the Event Registration section, fill out the form, select an event type, and click Register Now.

How can I search events?

Use the search box in the Events section and type the event name.

How can I filter events?

Select a category from the dropdown menu to view specific events.

How do I find nearby events?

Click the "Find Nearby Events" button and allow location access.

How do I clear saved preferences?

Click the "Clear Preferences" button in the registration section.
